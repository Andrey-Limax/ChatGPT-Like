## 💬 ChatGPT-Like

Interface conversacional inspirada no ChatGPT, construída com foco em aprendizado e experimentação com LLMs.

## 🚀 Como rodar
```bash
npm install
npm run dev
```

## 🛠 Tech Stack

- **Frontend:** React + TypeScript
- **Estilização:** Tailwind CSS
- **Build:** Vite

## 🤖 Sobre o projeto

Projeto desenvolvido para explorar a construção de interfaces de chat com IA generativa. A ideia é replicar a experiência do ChatGPT — histórico de mensagens, rolagem suave, input com envio por Enter — e evoluir com integrações de APIs como OpenAI ou modelos open-source.

> Parte de um portfólio focado em automação, bots e sistemas com IA.
